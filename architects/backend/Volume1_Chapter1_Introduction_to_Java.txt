1. What is Java?
==================================================

Interview Answer (30 seconds):
Java is a high-level, object-oriented, class-based programming language developed by Sun Microsystems (now Oracle). It follows the principle of "Write Once, Run Anywhere" (WORA) by compiling source code into platform-independent bytecode that runs on the Java Virtual Machine (JVM).

Key Characteristics:
- Object-Oriented
- Platform Independent
- Strongly Typed
- Automatic Garbage Collection
- Rich Standard Library
- Multithreading Support
- Secure Execution Environment

--------------------------------------------------
2. Why was Java created?
--------------------------------------------------

Before Java:
- Programs were compiled for a specific operating system.
- Porting software required recompilation and platform-specific changes.

Java Solution:
Source Code (.java)
      |
      v
Java Compiler (javac)
      |
      v
Bytecode (.class)
      |
      v
JVM
      |
      v
Windows / Linux / macOS

This architecture allows the same compiled bytecode to execute on any platform with a compatible JVM.

10. Frequently Asked Interview Questions
--------------------------------------------------

Q1. Why is Java platform independent?
Answer:
Because Java compiles source code into bytecode, which is executed by the JVM instead of directly by the operating system.

Q2. Is Java 100% object-oriented?
Answer:
No. Primitive data types (int, double, boolean, etc.) are not objects.

Q3. What does WORA mean?
Answer:
Write Once, Run Anywhere. Compile once into bytecode and execute on any platform with a JVM.

Q4. Why is Java considered robust?
Answer:
Strong type checking, exception handling, automatic garbage collection, and runtime checks.

Q5. Why is Java still widely used for enterprise applications?
Answer:
Stability, scalability, mature frameworks (Spring), excellent tooling, and long-term support.

--------------------------------------------------
11. Senior-Level Cross Questions
--------------------------------------------------

Q: If Java is platform independent, why do we need different JVMs?
A:
The bytecode is platform independent, but the JVM itself must translate bytecode into native machine instructions for each operating system and CPU architecture.

Q: Does Java compile to machine code?
A:
Initially to bytecode. At runtime, the Just-In-Time (JIT) compiler compiles frequently executed bytecode into native machine code.
